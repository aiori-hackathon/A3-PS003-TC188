## Validation results (40-sensor pilot, mean ± SD over seeds 0–2)

| Arm | Pooled MAE (veh / 5 min) |
|---|---|
| Centralised B1 | 19.743 ± 0.093 |
| Local-only | 19.872 ± 0.085 |
| Geographic FedAvg | 20.158 ± 0.047 |
| IID-like FedAvg | 20.228 ± 0.017 |
| Historical-average reference | 25.779 |

- B0 (without calendar features): 22.255 ± 0.102.
- Each FedAvg round sends 475,304 bytes of model updates.
- **Caveat on comparisons:** three seeds with the same direction is not statistical significance. The pilot is underpowered, and the IID-versus-geographic difference is **not** statistically established.
- **Caveat on labels:** the mapping from tensor rows to station IDs is supported by strong indirect evidence but is unconfirmed by provenance, so every District, client and type label is provisional.
